# Repositorio ORVEX OS

Repositorio privado: https://github.com/pablete260283/Orvex-OS

La primera entrega contiene Qt/QML, núcleo SQLite, contratos de integración, vista HTML, pruebas y documentación. Se conserva el commit inicial y el .gitignore existente. El README se amplía con las instrucciones del prototipo.

No se cambian la visibilidad, los permisos ni la configuración del repositorio. El pipeline se incluye para pruebas posteriores; no se declara aprobado hasta comprobar su ejecución.

El workflow se inicia manualmente desde Actions. No se ejecuta al subir código para evitar consumir minutos sin revisar antes la disponibilidad gratuita.
