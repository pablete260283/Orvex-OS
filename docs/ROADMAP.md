# Roadmap después de 0.2

1. Revisar el PR y la vista interactiva 0.2; probar Windows/TV y registrar defectos de foco, fuentes o DPI.
2. Corregir resultados de esa revisión antes de integrar cambios en main.
3. Preparar un paquete de escritorio reproducible y medir renderizado/consumo sobre hardware autorizado.
4. Validar la entrada de un mando como fuente de acciones lógicas en una fase independiente.
5. Conectar una biblioteca local autorizada detrás de los contratos actuales; importación y cambios de metadatos siempre bajo control del usuario.
6. Diseñar PIN/autenticación antes de presentar protección infantil como segura.

No desarrollar distribución Linux ni integrar hardware/servicios reales durante esta entrega visual. Mantener historial, pruebas y evidencia en GitHub. No asumir gastos ni alterar la configuración del equipo del usuario sin autorización.
