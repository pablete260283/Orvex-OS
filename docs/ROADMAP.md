# Próximas entregas de la fase visual

1. Revisar este diseño: jerarquía, legibilidad a distancia, densidad y navegación.
2. Iterar pantallas de detalle, filtros y estados vacíos/error con datos de prueba.
3. Extraer páginas dedicadas de la composición raíz cuando se incorporen esos flujos.
4. Probar la aplicación Qt en Windows y un televisor físico; medir escalado DPI, tiempos de cuadro y consumo.
5. Validar un mando como fuente de acciones lógicas en una fase de integración independiente.
6. Conectar una biblioteca local autorizada detrás de los contratos, después de aprobar el diseño.

No se instalará Linux, no se asumirá costo ni se modificará la configuración del equipo durante la fase visual. El repositorio remoto del proyecto es pablete260283/Orvex-OS.
